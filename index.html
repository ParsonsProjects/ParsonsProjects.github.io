    Everything on one page

    I'm Alan Parsons, a software developer. I make games, developer tools and small web apps. Outside of code I like time travel stories, space, and puzzle games where nothing is hidden.

    • Puzzles & Mortar

      A free browser game of maths and word puzzles. Every puzzle you solve earns a building for a city you plan yourself. Made with 5 to 13 year olds in mind, but anyone can play. No accounts and no adverts. Live, in development since 2022.

      puzzlesandmortar.com

    • Grove Bench

      An open-source Windows app for running several Claude Code sessions at once, each in its own git worktree and terminal so they don't overwrite each other's changes.

      Source on GitHub

    • Deep Keep

      A free tactical roguelite in the browser with no hidden dice. Every swing is rolled up front and shown, so each fight is a full-information puzzle. A run takes about ten minutes.

      playdeepkeep.com

    • Deep Dungeon

      A text adventure where you can type anything. A rules engine decides what happens and a language model describes it. In progress.

    • Tarsier

      One of my early side projects, from 2016: an open-source Chrome extension that rolled the best Trello extensions into one, built with Mithril.js.

      Source on GitHub

    • Fluid Gallery

      My first public project, from 2015: an open-source jQuery plugin where images grow out of the page into a lightbox, with galleries, titles and support back to Internet Explorer 8.
